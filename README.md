# Hesabyar — نرم‌افزار حسابداری شخصی فارسی (نام کاری، قابل تغییر)

> این مجموعه مستندات برای **عامل‌های هوش مصنوعی کدنویس** و توسعه‌دهنده نوشته شده است.
> ابتدا `CLAUDE.md` و سپس اسناد `docs/` را بخوانید. نام پروژه فقط یک placeholder است و در `Directory.Build.props` (`RootNamespace`) متمرکز می‌شود.

## ۱. خلاصه محصول
اپلیکیشن حسابداری شخصی **آفلاین-اول**، با **دفترداری دوطرفه در پشت صحنه** و رابط ساده، بهینه برای **فارسی، راست‌چین و تقویم شمسی**، ساخته‌شده با **.NET MAUI (C#)**. Target Frameworkهای Android و Windows فعال‌اند. یادآورها اعلان زمان‌بندی‌شده بومی در Android و Windows دارند، نوبت‌های تراکنش تکرارشونده هنگام شروع/بازگشت برنامه آماده می‌شوند و گزارش‌های مالی با خروجی Excel/CSV ارائه شده‌اند؛ ثبت تراکنش دفتر کل همچنان نیازمند تأیید کاربر است. iOS در اسناد محصول باقی است اما TFM و CI مستقل آن هنوز اضافه نشده‌اند. هدف: محصول تجاری با نسخه Pro (فعلاً بدون پرداخت، با Feature Flag).

## ۲. تصمیم‌های قفل‌شده (نسخه ۲ — بازنگری‌شده با شواهد بازار، ببینید `docs/10-market-insights.md`)

| دیگر MVP | حساب/دسته، گزارش و نمودار، Excel/CSV، بکاپ خودکار + انتقال گوشی، قفل، شمسی/RTL، تومان/ریال |

## ۴. فرض‌های ثبت‌شده (در صورت اشتباه اصلاح شود)
1. نسخه هدف: .NET 10؛ SDK در `global.json` قفل شده و با roll-forward محدود به Feature Band به‌روز می‌شود.
2. نسخه بسته‌ها در `Directory.Packages.props` ثبت و هنگام ارتقا با NuGet بررسی می‌شود.
3. اسناد به فارسی نوشته شده؛ شناسه‌های کد، نام کتابخانه‌ها و قواعد به انگلیسی.
