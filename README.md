# Hesabyar — نرم‌افزار حسابداری شخصی فارسی (نام کاری، قابل تغییر)

> این مجموعه مستندات برای **عامل‌های هوش مصنوعی کدنویس** و توسعه‌دهنده نوشته شده است.
> ابتدا `CLAUDE.md` و سپس اسناد `docs/` را بخوانید. نام پروژه فقط یک placeholder است و در `Directory.Build.props` (`RootNamespace`) متمرکز می‌شود.

## ۱. خلاصه محصول
اپلیکیشن حسابداری شخصی **آفلاین-اول**، با **دفترداری دوطرفه در پشت صحنه** و رابط ساده، بهینه برای **فارسی، راست‌چین و تقویم شمسی**، ساخته‌شده با **.NET MAUI (C#)** برای Android، iOS و Windows. هدف: محصول تجاری با نسخه Pro (فعلاً بدون پرداخت، با Feature Flag).

## ۲. تصمیم‌های قفل‌شده (نسخه ۲ — بازنگری‌شده با شواهد بازار، ببینید `docs/10-market-insights.md`)

| حوزه | تصمیم |
|---|---|
| هسته حسابداری | دفترداری دوطرفه پشت صحنه؛ رابط ساده (دریافت/پرداخت/انتقال، طلب/بدهی) |
| ذخیره‌سازی | آفلاین کامل؛ SQLite + **SQLCipher** با EF Core؛ بدون ثبت‌نام |
| ویژگی‌های قهرمان MVP | **ثبت از پیامک (Android)**، **دفتر بدهی/طلب**، **چک**، **وام/اقساط**، یادآور |
| دیگر MVP | حساب/دسته، گزارش و نمودار، Excel/CSV، بکاپ خودکار + انتقال گوشی، قفل، شمسی/RTL، تومان/ریال |
| نسخه ۱٫۱ | تکرارشونده/الگو، بودجه ماهانه، پیوست رسید، PDF، برچسب |
| نسخه ۱٫۲ | Windows، Sync با سرور خودمان، Pro (آزمون رایگان بلند) و پرداخت |
| **حذف/عقب‌افتاده** | OCR، چندارزی (UI)، دارایی‌ها، AI، E2EE، چندکاربره، Workspace، جدول‌های رزروی |
| ارز | `long` ریال؛ تومان فقط نمایش؛ فیلد ارز در حساب (آماده چندارزی بدون UI) |
| زبان/تقویم | فارسی اول + i18n؛ شمسی پیش‌فرض، میلادی قابل انتخاب، ارقام فارسی/لاتین |
| امنیت | قفل PIN/بیومتریک + SQLCipher؛ `IKeyProvider` برای آینده |
| پلتفرم | اول Android و iOS؛ Windows بعد (۱٫۲) |
| معماری | Clean Architecture ماژولار + CommunityToolkit.Mvvm + Shell + DI؛ سرویس هر Feature |
| تست/CI | xUnit: واحد + یکپارچه دیتابیس؛ CI اولیه فقط برای Core |

## ۴. فرض‌های ثبت‌شده (در صورت اشتباه اصلاح شود)
1. نسخه هدف: آخرین **.NET LTS** که MAUI از آن پشتیبانی می‌کند (در زمان نگارش .NET 10؛ **حتماً** با https://learn.microsoft.com تأیید شود).
2. شماره نسخه بسته‌های NuGet عمداً ذکر نشده و باید هنگام راه‌اندازی بررسی شوند.
3. اسناد به فارسی نوشته شده؛ شناسه‌های کد، نام کتابخانه‌ها و قواعد به انگلیسی.
