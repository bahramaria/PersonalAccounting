# راهنمای بسته داخلی حساب‌یار

این راهنما برای ارزیابی داخلی نسخه محلی Android و Windows است؛ این بسته‌ها انتشار عمومی یا تأییدشده برای فروشگاه نیستند.

## تولید بسته‌ها

1. در GitHub مخزن را باز کنید.
2. از بخش Actions، گردش‌کار **Internal release packages** را انتخاب کنید.
3. گزینه Run workflow را بزنید و Branch برابر `feature/personal-accounting-mvp` را انتخاب کنید.
4. پس از موفقیت هر دو Job، از صفحه همان اجرا Artifactهای زیر را دریافت کنید:
   - `Hesabyar-Android-APK`
   - `Hesabyar-Windows-x64`

این گردش‌کار دستی است و با هر Commit اجرا نمی‌شود. Artifactها ۳۰ روز نگهداری می‌شوند.

## نصب Android

1. فایل APK را روی دستگاه آزمایشی منتقل کنید.
2. اجازه نصب برنامه از منبع مورد استفاده را در تنظیمات Android فعال کنید.
3. APK را نصب و برنامه را اجرا کنید.
4. در اولین اجرا، ساخت حساب و موجودی اولیه را در Onboarding انجام دهید.
5. برای آزمایش نسخه جدید، ابتدا از داخل برنامه بکاپ رمزدار بگیرید و فایل آن را خارج از حافظه برنامه نگهداری کنید.

## اجرای Windows

1. Artifact ویندوز را استخراج کنید.
2. تمام محتویات پوشه را در کنار هم نگه دارید؛ اجرای فایل EXE به فایل‌های همراه وابسته است.
3. فایل اجرایی `Hesabyar.App.exe` را اجرا کنید.
4. اگر Windows App Runtime روی سیستم موجود نباشد، Runtime موردنیاز MAUI را نصب کنید.
5. پیش از جایگزینی نسخه قبلی، از داده‌ها بکاپ بگیرید.

## بکاپ، ارتقا و بازیابی

- پیش از نصب نسخه جدید، از مسیر تنظیمات یک بکاپ با گذرواژه حداقل ۸ کاراکتری تهیه کنید.
- فایل بکاپ را در همان دستگاه و همان پوشه دیتابیس نگه ندارید؛ آن را در فضای امن دیگری ذخیره کنید.
- در صورت نصب مجدد برنامه یا انتقال به دستگاه دیگر، فایل بکاپ رمزدار را انتخاب و گذرواژه آن را وارد کنید.
- پیش‌نمایش نسخه و تاریخ بکاپ را بررسی کنید و فقط پس از تأیید، بازیابی را ادامه دهید.
- بازیابی، دیتابیس فعلی را جایگزین می‌کند؛ پیش از تأیید نهایی، نام و تاریخ فایل را کنترل کنید.
- اگر APK جدید با گواهی امضای متفاوت باشد، Android اجازه نصب روی نسخه قبلی را نمی‌دهد. در این حالت ابتدا بکاپ بگیرید، نسخه قبلی را حذف و سپس APK جدید را نصب کنید. برای بتای قابل ارتقا باید Keystore ثابت و امن در GitHub Secrets تنظیم شود.

## محدودیت‌های شناخته‌شده و گیت‌های انتشار

- شناسه بسته Android فعلی `com.example.hesabyar` موقت است و پیش از انتشار عمومی باید با شناسه نهایی و تحت مالکیت ناشر جایگزین شود.
- بسته داخلی Android با امضای انتشار فروشگاهی تولید نمی‌شود؛ برای توزیع پایدار باید Keystore و نسخه‌گذاری رسمی تنظیم شود.
- اعتبارسنجی Runtime رمزنگاری SQLite روی دستگاه واقعی Android و Windows هنوز گیت انتشار است؛ موفقیت Build به‌تنهایی این مورد را تأیید نمی‌کند.
- RTL، تم روشن/تاریک، Font Scale، اعلان‌ها و رفتار OEM باید روی دستگاه‌ها و نسخه‌های واقعی سیستم‌عامل بازبینی شوند.
- دریافت خودکار SMS بانکی و مجوزهای آن تابع سیاست‌های Android و فروشگاه است؛ آزمون میدانی SMS طبق تصمیم محصول پس از تکمیل محصول انجام می‌شود.
- این نسخه محلی است؛ ورود ابری، Server، Sync، پرداخت و ارسال عملیاتی OTP فعال نیستند.
